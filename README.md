# 就活支援アプリ

就職活動を効率的に管理・サポートするためのWebアプリケーションです。

## 主な機能

1. シンプル進捗トラッカー 📊
   - 応募企業の情報や選考状況の一元管理
   - 選考ステータスの追跡
   - 締切日アラート機能

2. ES・面接回答ストックノート 📝
   - エントリーシートの設問・回答管理
   - 面接質問の回答テンプレート
   - キーワード検索機能

3. 企業情報比較メモ ⚖️
   - 企業情報の項目別整理
   - 複数企業の比較表示
   - メモ機能

4. 就活タスク管理ツール ✅
   - タスクの登録・管理
   - 優先度設定
   - 進捗状況トラッキング

## 技術スタック

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage（データ保存）

## 使用方法

1. index.htmlをブラウザで開く
2. 必要な機能のページに移動
3. データは自動的にブラウザに保存されます

## 注意事項

- このアプリはローカルストレージを使用するため、ブラウザのデータをクリアすると保存されたデータは失われます。
- 定期的なデータのバックアップをお勧めします。
